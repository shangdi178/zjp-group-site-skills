# ZJP Group Site Skills

邹建平课题组网站开发与维护的可复用技能集合。

> **注意：** 本仓库使用软连接（Junction）指向实际 skill 目录 `C:\Users\Hepu\.cc-switch\skills\`。修改此处文件会直接修改原始 skill 文件，反之亦然。
>
> 不要在 Windows 资源管理器中直接删除 Junction 目录，应使用 `rmdir` 命令。

## Skills

- `powereasy-template-adapter` — PowerEasy CMS 模板适配指南
- `zup-group-site-manager` — ZJP 课题组网站管理手册
